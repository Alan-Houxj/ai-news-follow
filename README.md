# AI 时讯跟进

**每天早上 8 点，一份帮你筛好、看完就能聊的 AI 日报，自动送到你的飞书。**

你不是没时间刷新闻，你是没时间在一百条噪音里找出那三条真正重要的事。
这个工具替你盯着 AI 圈最值得追的源头，把当天发生的事挑出来、讲清楚、附上原文——
你只需要每天早上花 30 秒扫一眼，就知道今天该聊什么、该关注什么。

它是一个通用的 [Agent Skill](https://agentskills.io)：一条命令装进你正在用的 AI Agent，
之后就长在你身边，天天替你盯 AI 圈。Claude Code、ZCode、Cursor、Codex CLI 等主流工具
都能装，不绑定任何一家。不折腾服务器、不折腾数据库，装完就能用。

## 你每天早上会看到什么

一条飞书消息，长这样：

> **📰 AI 日报 · 2026-09-03（周四）· 15 条**
>
> 🔥 **今日爆点**　模型层进入"性能翻倍 + 成本砍半"的密集发布期——Google 与
> Anthropic 同日发新模型，Agent 推理成本成为主战场……
>
> **1. 🔥 Gemini 3.8 Flash 发布**　`前沿动态`
> Google 发布两款新模型，主打高性价比推理，Cyber 版面向安全场景
> 👉 阅读原文
>
> **2. 🔥 Cursor 推出 Origin：GitHub 的智能体替代方案**　`产品动态`
> 面向 AI 智能体的代码托管与协作空间，冲击传统开发者工作流
> 👉 阅读原文
>
> **3. 李飞飞首个多模态世界模型 Atlas 发布**　`前沿动态`
> 从零开始预训练，几张图就能构建对物理世界的理解
> 👉 阅读原文
>
> ……

这条消息的结构，就是为了"快速刷完"设计的：

- **开头一句"今日爆点"**：两三句话讲清今天 AI 圈的主线，帮你建立当日叙事——
  不是孤立的一条条新闻，而是"今天到底发生了什么、趋势往哪走"
- **每条一句话说清是什么**：标题本身就讲完了，不用点进去才知道讲啥
- **再补一句为什么值得关注**：摘要只做导航，不替你下结论
- **点开就是原文**：链接从采集层一路带到你面前，任何环节不改写。拿不准的，
  点进去自己核实——不传二手信息

## 日报去了哪

一条消息看完就沉底，但数据不会。同一份日报，同时落在飞书的三个地方：

| 去处 | 什么时候用 |
|---|---|
| **飞书私聊消息** | 每天早上扫一眼，知道今天发生了什么 |
| **多维表格「AI 日报」** | 想筛选、统计、检索历史时——比如"上个月 Anthropic 发了哪些东西" |
| **云文档「AI 日报归档」** | 想按时间线回顾一段行业脉络，像翻一本持续更新的杂志 |

表格里每条记录有 8 个字段：标题、摘要、原文链接、来源、分类、标签、重要度、日期。
攒上一个月，这就是一份你自己的 AI 行业动态数据库——随时可查，越攒越值钱。

| 来源 | 覆盖什么 |
|---|---|

| Hugging Face 博客 | 开源模型、数据集、榜单风向 |
| TechCrunch AI | 海外 AI 融资、产品、商业动态 |
| The Verge AI | 海外 AI 产品与商业动态 |
| MIT Tech Review AI | 深度技术分析 |
| Hacker News AI 热帖 | 海外社区热议的 AI 高票帖 |
| InfoQ 中文 | 中文技术媒体的 AI 报道 |
| arXiv cs.AI | 每日最新 AI 论文 |
| arXiv cs.CL | 每日最新 NLP 论文 |

每天这十一个源头加起来上百条原始信息，经过三重处理——**去噪**（剔除无关内容）、
**去重**（多源报道同一件事时合并）、**按重要度排序**——最后只留 10 到 30 条。

## 为什么值得装

**省下的是你筛选的时间，不是你的判断**
AI 摘要负责"把这条消息讲清楚"，但结论永远由你点开原文自己下。它不制造观点，
只负责把值得你花注意力的东西递到你眼前。

**装一次，天天都在**
作为一个标准 Agent Skill，一条命令装进你正在用的 AI Agent。装完就没有"下次再用"
这回事了——它就是你的 AI 资讯接口，对话里说一句"今天的日报"就能跑。

**你的数据，只经过你自己**
数据流是"信息源 → 你的 Agent → 你自己的飞书"，不经过任何第三方服务器。
仓库不含任何密钥，飞书配置只存在你本地的 config.json 里。

**每天都在，风雨无阻**
某个信息源偶尔挂掉会自动跳过，推送失败会自动重试——日报明天、后天、大后天都会按时出现。

## 怎么开始

### 第 1 步：安装 Node.js

装 Skill 用到的安装器（`npx skills`）基于 Node.js，先装一次，以后不用再管。打算用下方"手动复制"方式装 Skill 的话，这一步可以跳过。

- **Windows**：打开 PowerShell，执行
  ```powershell
  winget install OpenJS.NodeJS.LTS
  ```
- **macOS**：打开终端，执行
  ```bash
  brew install node
  ```
- 或者直接去 [nodejs.org](https://nodejs.org) 下载 LTS 版本安装包，一路下一步。

装完验证一下：`node --version` 能打印出版本号（如 `v20.11.0`）就成功了。

### 第 2 步：确认电脑里有 Python

日报的采集脚本是用 Python 写的，电脑里要有 Python 3.10 或更高版本。这一步不能跳过。

- **Windows**：打开 PowerShell，执行
  ```powershell
  winget install Python.Python.3.12
  ```
- **macOS**：打开终端，执行
  ```bash
  brew install python
  ```
- 或者直接去 [python.org](https://python.org) 下载 3.10 以上版本，一路下一步。

装完验证一下：`python --version` 能打印出版本号（如 `Python 3.12.8`）就成功了。

### 第 3 步：安装 Skill

在终端执行这一条命令：

```bash
npx skills add https://github.com/Alan-Houxj/ai-news-follow -g
```

它会自动找到并安装仓库里的 `ai-news` 技能。

如果你的 Agent 没有被自动识别，也可以手动安装：把仓库里 `skills/ai-news/` 这个
文件夹，复制到你的 Agent 的技能目录（各家路径不同，例如 Claude Code 是
`~/.claude/skills/`，以你 Agent 的文档为准）。

### 第 4 步：对话里跑一次

打开你的 Agent，说：

> 帮我跑一下今天的 AI 日报

日报会直接出现在对话里。这一版先不接飞书，看看内容是不是你要的。

### 第 5 步（可选）：接入你自己的飞书

直接在对话里说"**把日报接入我的飞书**"——Agent 现场引导，你只需点一次链接、
扫一次码，其余自动完成（建表、授权、归档、测试消息），约 5 分钟。
细节见 **[docs/setup.md](docs/setup.md)**。

### 第 6 步（可选）：每天自动运行

在你的 Agent 里设一个定时任务，以后每天早上自动跑，见
**[docs/scheduling.md](docs/scheduling.md)**。
